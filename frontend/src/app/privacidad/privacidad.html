En Sumando Capacidades respetamos la privacidad de las personas que utilizan la plataforma. Esta política explica qué información se recoge a través de la aplicación y con qué finalidad se utiliza.

Sumando Capacidades es una entidad ficticia creada con fines académicos como parte de un proyecto de Desarrollo de Aplicaciones Web. Los datos introducidos en esta aplicación deben utilizarse únicamente con fines de demostración y prueba.

1. Responsable del tratamiento

A efectos de esta aplicación, la gestión de los datos corresponde a Sumando Capacidades, entidad ficticia utilizada exclusivamente para el desarrollo y demostración del proyecto.

Para cualquier consulta relacionada con la privacidad o el uso de los datos puede utilizarse el formulario de contacto disponible en la propia plataforma.

2. Datos personales que puede tratar la aplicación

Dependiendo de las funcionalidades utilizadas, la aplicación puede almacenar los siguientes datos:

  • Datos identificativos: nombre y apellidos.
  • Datos de contacto: correo electrónico y, cuando se facilite, número de teléfono.
  • Datos de perfil: fecha de nacimiento, disponibilidad, áreas de interés y habilidades indicadas durante el registro.
  • Datos de participación: actividades en las que una persona se inscribe y estado de sus inscripciones.
  • Datos de contacto con la entidad: nombre, correo electrónico, asunto y contenido de los mensajes enviados mediante el formulario.
  • Datos de autenticación: correo electrónico y contraseña. Las contraseñas se almacenan de forma codificada y no como texto legible.

La aplicación no está diseñada para solicitar información especialmente sensible como datos médicos, ideología, religión u otra información perteneciente a categorías especiales de datos personales.

3. Finalidades del tratamiento

Los datos utilizados por la plataforma tienen como finalidad permitir el funcionamiento de sus principales servicios.

  • Crear y gestionar cuentas de usuario.
  • Permitir el inicio y cierre de sesión.
  • Gestionar perfiles de personas voluntarias.
  • Gestionar inscripciones y cancelaciones en actividades de voluntariado.
  • Mostrar las actividades asociadas a cada usuario.
  • Gestionar consultas enviadas a través del formulario de contacto.
  • Permitir la administración de actividades, participantes, propuestas y mensajes cuando corresponda.

4. Base jurídica

En un entorno real, el tratamiento de datos personales debe contar con una base jurídica adecuada conforme al Reglamento General de Protección de Datos.

En esta aplicación académica, los datos se facilitan voluntariamente por las personas que utilizan las funcionalidades de registro, inscripción y contacto.

El tratamiento se limita a las funcionalidades necesarias para demostrar el funcionamiento técnico del proyecto.

5. Conservación de los datos

Los datos se mantienen en la base de datos de desarrollo mientras sean necesarios para las pruebas y demostraciones de la aplicación.

Al tratarse de un proyecto académico, no se establecen en esta demostración periodos comerciales o administrativos de conservación. Los datos de prueba pueden eliminarse cuando dejen de ser necesarios para el desarrollo o evaluación del proyecto.

6. Comunicación de datos

La aplicación no tiene como finalidad comercializar, vender ni ceder datos personales a terceros.

Los datos almacenados se utilizan exclusivamente dentro de las funcionalidades de la plataforma y de su entorno de desarrollo.

7. Derechos de las personas usuarias

La normativa de protección de datos reconoce, entre otros, los derechos de:

  • Acceso: conocer qué datos personales se están tratando.
  • Rectificación: solicitar la corrección de datos incorrectos.
  • Supresión: solicitar la eliminación de los datos cuando proceda.
  • Oposición: oponerse a determinados tratamientos.
  • Limitación: solicitar que el tratamiento de los datos quede restringido en determinadas circunstancias.
  • Portabilidad: solicitar los datos en un formato adecuado cuando resulte aplicable.

En una organización real, estos derechos pueden ejercerse frente al responsable del tratamiento. En esta aplicación de demostración puede utilizarse el formulario de contacto para realizar cualquier consulta relacionada con los datos.

También puede consultarse información sobre protección de datos y ejercicio de derechos en la Agencia Española de Protección de Datos .

8. Seguridad de la información

La aplicación incorpora medidas técnicas relacionadas con la autenticación y el control de acceso.

  • Las contraseñas no se almacenan en texto plano.
  • La autenticación utiliza tokens para identificar las sesiones de usuario.
  • Determinados recursos del backend requieren autenticación.
  • Las funciones administrativas están diferenciadas mediante roles de usuario.

Estas características forman parte del desarrollo técnico del proyecto y no deben interpretarse como una certificación de seguridad o auditoría profesional de la plataforma.

9. Almacenamiento en el navegador

La aplicación puede utilizar almacenamiento local del navegador para conservar temporalmente información necesaria para mantener la sesión del usuario, como el token de autenticación y los datos básicos del perfil.

El proyecto no declara el uso de herramientas de analítica, publicidad comportamental ni sistemas de seguimiento comercial.

10. Contacto

Para cualquier consulta relacionada con esta política puede utilizarse el formulario de contacto de Sumando Capacidades .

11. Actualización de esta política

Esta información podrá actualizarse cuando cambien las funcionalidades de la aplicación o los datos tratados por el proyecto.
